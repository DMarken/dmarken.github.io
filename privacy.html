Privacy policy

Last updated November 15, 2026.

Private Files Tool is a private, single-user tool. Its only user is its owner, and it accesses only its owner's own Google account.

What it accesses

With its owner's permission, granted through Google's own sign-in screen, the tool can read and change the owner's Google Drive files, Docs, Sheets, Slides, Forms, Gmail, Calendar, Tasks, Contacts, YouTube account and the Google Photos items it adds or the owner picks.

Where the data goes

  • The tool runs only on its owner's own computer. It has no server.
  • Data moves only between the owner's computer and Google's services.
  • The tool doesn't sell, share, rent or transfer any data to anyone, and it doesn't use any data for advertising.
  • Sign-in credentials stay on the owner's computer.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the tool's access at any time from their Google Account's third-party connections page.
